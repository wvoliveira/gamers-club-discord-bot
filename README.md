# GCBOT

Discord bot to get matches information from the Gamers Club.

## Install

```bash
make
./gcbot -t <discord token>

# If you using raspberry too:
# make raspberry
# ./gcbot -t <discord token>
```

Use scripts from scripts folder to create Discord commands.
