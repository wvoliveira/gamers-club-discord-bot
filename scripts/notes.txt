To clarify, Source servers have 4 ports they use:
    hostport, specified via -port on the command line. Default: 27015. On TCP, this is used for rcon. On UDP, this is used for A2S information queries to the server, including getting the...
    clientport, specified via -clientport on the command-line. Default: 27005. On UDP, used for client connections.
    steam port, specified via -sport or -steamport on the command-line. Default: 26900... but really uses 26901 on most games. On UDP, communicates with the Steam servers.
    SourceTV port, specified via +tv_port on the command line. Default: 27020. On UDP, used for client connections for SourceTV. -nohltv will disable this port entirely.

On most game servers, -strictportbind will make the server error out if it tries to start on an already used port. CS:GO uses a different command for this (if anyone knows it, feel free to chime in). If this isn't set, the server may rebind to a higher port when you restart it if it thinks the previous instance hasn't shut down yet.

Now, there are other issues with CS:GO. Specifically, -ip likely needs to be set to your real IP, while +net_addr needs to be set to your external IP.
